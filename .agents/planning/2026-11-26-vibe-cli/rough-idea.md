# Rough idea

Implement support for the Mistral Vibe CLI (https://docs.mistral.ai/llms/vibe/code/llms.txt)
in rolebox (https://github.com/juanrh/rolebox), at the same level of support as the
existing OpenCode integration — concretely, the level the repo already reaches for
Codex, its other CLI-only harness: `rolebox sync vibe`, a stdio MCP server entry,
native agent files, skills, registry/capability integration, docs and tests.
